Mitcad is released under the MIT licence (see LICENSE). The Linux AppImage
also contains the following third-party components. The files named here
are in usr/share/doc of the AppImage (unpack it with --appimage-extract).

Qt 6 (usr/lib/libQt6*.so*, usr/plugins)
  Licence: GNU LGPL version 3 (https://www.gnu.org/licenses/lgpl-3.0.html).
  Mitcad links Qt dynamically; the Qt libraries in usr/lib can be replaced
  with other builds of the same Qt version. Qt's source code is available
  from https://download.qt.io/ and https://www.qt.io/ .

ICU (usr/lib/libicu*.so*, used by Qt)
  Licence: the Unicode licence (https://www.unicode.org/license.txt).

Open CASCADE Technology (usr/lib/libTK*.so*)
  Licence: GNU LGPL version 2.1 with the Open CASCADE exception. Linked
  dynamically; source code at https://dev.opencascade.org/ . Version 8.0.1
  with changes of Mitcad's that speed up booleans, the face merge after
  them and the shape checker on faces with many edges, that let fillets run
  over faces narrower than they are, that fix other failures and crashes of
  the fillet, and that make an allocation that fails throw instead of
  crashing; the patches are in Mitcad's source code
  (third_party/vcpkg-ports/opencascade).

Other libraries from vcpkg (for example libpng, bzip2, Brotli)
  Their licence texts are in mitcad/licenses/vcpkg/<library>/copyright.

Libraries of the build system (Ubuntu 24.04) that a Linux desktop may
lack (for example xcb's utility libraries, xkbcommon, GLib, D-Bus,
Kerberos)
  Linked dynamically; their licence texts are in <package>/copyright.

Droid Sans (bundled font for sketch text)
  Apache License 2.0; see mitcad/licenses/droid-sans/LICENSE.txt.

QtKeychain (https://github.com/frankosterfeld/qtkeychain), linked
statically into mitcad
  The live updates' credentials in the system's keychain. BSD-3-Clause,
  Copyright (C) 2011-2015 Frank Osterfeld and its contributors; see
  mitcad/licenses/qtkeychain/COPYING. It loads libsecret (GNU LGPL
  version 2.1) at run time when the system has it; libsecret is not part
  of the AppImage.

The AppImage runtime (the start of the AppImage file, which mounts or
unpacks the rest)
  AppImage's type2-runtime (https://github.com/AppImage/type2-runtime), MIT
  licence, unchanged but for its cleared update information. It is a
  program of its own, statically linked with libfuse (GNU LGPL version
  2.1), squashfuse (BSD-2-Clause), zstd (BSD-3-Clause), zlib (zlib
  licence) and musl (MIT); `<AppImage> --appimage-help` lists them.
  Sources: the runtime at https://github.com/AppImage/type2-runtime (with
  the build scripts that link it), libfuse at
  https://github.com/libfuse/libfuse . Under the LGPL you may relink the
  runtime with a modified libfuse from these sources; the runtime is not
  linked with Mitcad's own code.

Rust libraries compiled into mitcad and mitcad-cli
  Permissive licences (MIT, Apache-2.0, BSD and similar), checked by
  cargo-deny against core/deny.toml. Among them the TLS of live updates
  (connections to an MQTT broker): rustls (Apache-2.0, ISC or MIT),
  rustls-webpki and untrusted (ISC, Copyright 2015 Brian Smith), and ring
  (ISC, Copyright 2015-2025 Brian Smith, with code from BoringSSL under
  the Apache License 2.0 and the ISC licence, and from fiat-crypto under
  the MIT licence).

Only in builds with the render worker (the CMake option MITCAD_RENDER, not
in releases yet; docs/rendering.md): the executable usr/bin/mitcad-render,
which alone links the following; mitcad starts it for View > Rendered.
  Cycles (https://projects.blender.org/blender/cycles), Blender's path
  tracer, Apache License 2.0, linked statically into mitcad-render, with
  code it bundles under Apache-2.0, BSD-3-Clause and MIT; the licence
  texts are in mitcad/licenses/cycles (in builds with Cycles' CUDA device
  also cuew, Blender Foundation, Apache License 2.0 with a stricter
  trademark clause: cuew-license.txt; it loads the system's GPU driver,
  nothing of NVIDIA's is shipped). Open Image Denoise
  (https://github.com/RenderKit/oidn, usr/lib/libOpenImageDenoise*.so*),
  Apache License 2.0, with its trained weights (Apache License 2.0); see
  mitcad/licenses/openimagedenoise. From vcpkg, linked dynamically:
  Embree, oneTBB, OpenImageIO, OpenSSL (Apache-2.0); OpenColorIO,
  OpenEXR, Imath, pystring, libtiff, libjpeg-turbo, zstd, hwloc, OpenJPH,
  liblzma (BSD-style); pugixml, cgltf, yaml-cpp, fmt, robin-map,
  libdeflate (MIT); minizip-ng (zlib licence). Their licence texts are in
  mitcad/licenses/vcpkg/<library>/copyright.
